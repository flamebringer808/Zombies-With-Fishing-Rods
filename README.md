# Zombies With Fishing Rods (Forge 1.20.1)

Beware of the undead anglers! Certain zombies spawn holding fishing rods, casting lines to snag fleeing players and reel them into melee range.

---

## 🌟 Features

* **Reeling AI Mechanics**: Zombies spot targets at range, cast their bobber with realistic velocity and trajectory, hook the target, and pull them backward into danger.
* **Multiplayer Visual Sync**: Includes dedicated client-server network packets (ClientboundHookSyncPacket) to ensure fishing lines and bobbers render smoothly for all players.
* **Supported Mobs**: Zombies, Husks, Drowned, and Zombie Villagers.
* **Fully Configurable**: Set cast distance, reel strength, cooldowns, and spawn probabilities.
